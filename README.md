# SessionRun (Portfolio)

A shared real-time dashboard view for monitoring, intervening, and collaborating on long-running AI agent runs.

## Overview
- **Live Execution Tracking**: Real-time progress updates and step timeline visualization.
- **Human-in-the-Loop Gates**: Pause, review, approve, or decline sensitive agent actions.
- **Multi-Viewer Presence**: See active collaborators watching the run.
- **Keyboard Shortcuts**: Navigate steps (`J`/`K`), approve (`A`), and decline (`X`).

## Getting Started

### Installation
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```
